# PoopTracker 设计系统

> 版本：v1.0 | 日期：2026-06-25 | 方向：温暖日式生活手帐

---

## 一、当前 UI 存在的问题

### 1. 色彩系统：完全无色
- 所有 CSS 变量 chroma 值为 `0`，整个界面是纯灰度，没有任何品牌色
- 参考图中温暖的奶油色、柔和绿色、暖棕色在当前设计中完全缺失
- 图表颜色和日历热力图颜色硬编码在组件中，未纳入设计令牌系统

### 2. 视觉氛围：医疗器械感，而非健康生活工具
- 纯白背景 (`oklch(1 0 0)`) + 黑色文字 = 冰冷的"系统模板"感
- 参考图传达的是"温馨、亲切、生活化"，当前界面传达的是"数据录入表单"
- 没有任何插画、图标装饰、或氛围元素来软化"便便记录"这个话题的尴尬感

### 3. 排版：缺乏层次和个性
- 使用系统默认字体（Geist），没有体现产品个性
- 页面标题（"计时记录"、"今日记录"）仅用 `text-2xl font-bold`，缺乏设计感
- 大段留白但没有节奏感——内容区和间距是均匀的，没有视觉焦点

### 4. 交互反馈：几乎为零
- 计时器按钮（开始/停止）只有颜色切换，没有动画、脉冲、或状态暗示
- RecordCard 有 `hover:shadow-md` 但没有其他微交互
- 没有页面切换动画、列表入场动画、或骨架屏加载状态
- 日历热力图的色阶跳变明显（灰→绿-200→绿-400→绿-600→绿-800），缺乏渐进感

### 5. 移动端适配：完全缺失
- 顶部导航是水平排列的 5 个链接 + Logo，在窄屏上会溢出或挤压
- 没有汉堡菜单、底部 Tab Bar、或任何移动端导航方案
- `max-w-2xl` 的容器在手机上左右 padding 不足，内容贴边

### 6. 信息密度与空状态
- 首页"今日记录"空状态只是一行灰色文字，没有插画或引导
- 统计页在无数据时直接显示空图表，缺乏友好的空状态设计
- AI 分析页面的日期选择器是原生 `input[type=date]`，体验粗糙

### 7. 组件一致性
- 卡片组件 Card 有 `size` prop 但未被统一使用
- 表单页面（新增/编辑）和详情页面的布局风格不一致
- 删除操作使用浏览器原生 `confirm()`，与整体 UI 风格不搭

## 二、推荐设计方向

### 方向定位：**"温暖日式生活手帐"**

参考图的核心气质是：**温暖、圆润、手绘感、生活化**。这非常适合一个健康记录类 App——用亲切感化解尴尬，用手帐感增加记录的乐趣。

**关键词：**
- 暖色调基底（奶油米色背景，而非纯白）
- 圆润形态（大圆角卡片、胶囊按钮、圆形图标容器）
- 柔和渐变（而非硬切色块）
- 微妙的纹理和层次（阴影、毛玻璃、轻噪点）
- 活泼但不幼稚的图标和插画点缀
- 移动端优先的底部导航

**氛围参考提炼：**

| 元素 | 参考图特征 | 落地建议 |
|------|----------|---------|
| 背景 | 奶油白/米色 | `oklch(0.97 0.01 85)` 暖米色 |
| 主色 | 柔和绿/鼠尾草绿 | `oklch(0.65 0.12 155)` 治愈绿 |
| 强调色 | 暖橙/赤陶色 | `oklch(0.72 0.14 55)` 暖橙 |
| 卡片 | 大圆角 + 柔阴影 | `radius: 1.25rem`，多层柔和阴影 |
| 按钮 | 胶囊形、有图标 | 圆角 `9999px`，带微交互动画 |
| 字体 | 圆润、亲切 | 中文用霞鹜文楷/得意黑，英文用 Nunito/Quicksand |
| 插画 | 简笔画风格 | Lucide 圆润图标 + 自定义装饰元素 |

## 三、设计系统规范

### 3.1 颜色系统

```css
/* === Light Mode === */
:root {
  /* 基底色 - 暖调 */
  --background: oklch(0.975 0.008 85);        /* 奶油米色 */
  --foreground: oklch(0.18 0.02 60);           /* 深暖棕 */

  /* 卡片 & 弹出层 */
  --card: oklch(0.99 0.005 85);               /* 略暖的白 */
  --card-foreground: oklch(0.18 0.02 60);
  --popover: oklch(0.99 0.005 85);
  --popover-foreground: oklch(0.18 0.02 60);

  /* 主色 - 治愈绿（鼠尾草） */
  --primary: oklch(0.58 0.12 155);            /* 鼠尾草绿 */
  --primary-foreground: oklch(0.99 0.005 85); /* 近白 */

  /* 辅助色 - 暖沙色 */
  --secondary: oklch(0.93 0.03 75);           /* 暖沙 */
  --secondary-foreground: oklch(0.35 0.05 60);

  /* 静音色 */
  --muted: oklch(0.93 0.02 80);
  --muted-foreground: oklch(0.50 0.03 70);

  /* 强调色 - 暖橙/赤陶 */
  --accent: oklch(0.78 0.10 55);              /* 暖橙 */
  --accent-foreground: oklch(0.20 0.03 55);

  /* 危险色 */
  --destructive: oklch(0.58 0.20 25);
  --destructive-foreground: oklch(0.99 0 0);

  /* 边框 & 输入 */
  --border: oklch(0.90 0.02 80);              /* 暖灰边框 */
  --input: oklch(0.90 0.02 80);
  --ring: oklch(0.58 0.12 155);               /* 绿色聚焦环 */

  /* 圆角 */
  --radius: 1.25rem;

  /* 图表色板 - 温暖和谐 */
  --chart-1: oklch(0.58 0.12 155);   /* 鼠尾草绿 */
  --chart-2: oklch(0.72 0.14 55);    /* 暖橙 */
  --chart-3: oklch(0.68 0.10 85);    /* 琥珀 */
  --chart-4: oklch(0.55 0.10 200);   /* 雾蓝 */
  --chart-5: oklch(0.65 0.12 320);   /* 柔紫 */

  /* 新增语义色 */
  --success: oklch(0.62 0.15 145);   /* 成功绿 */
  --warning: oklch(0.75 0.12 70);    /* 警告黄 */
  --info: oklch(0.60 0.10 210);      /* 信息蓝 */

  /* 纹理 */
  --noise-opacity: 0.03;             /* 噪点纹理透明度 */
}
```

### 3.2 字体系统

```css
/* 字体栈 */
--font-display: "LXGW WenKai", "Nunito", sans-serif;  /* 标题：霞鹜文楷 */
--font-body: "Nunito", "LXGW WenKai", sans-serif;      /* 正文 */
--font-mono: "JetBrains Mono", monospace;               /* 计时器等宽 */

/* 字号梯度 */
--text-xs: 0.75rem;     /* 12px - 辅助文字 */
--text-sm: 0.875rem;    /* 14px - 次要文字 */
--text-base: 1rem;      /* 16px - 正文 */
--text-lg: 1.125rem;    /* 18px - 小标题 */
--text-xl: 1.25rem;     /* 20px - 卡片标题 */
--text-2xl: 1.5rem;     /* 24px - 页面标题 */
--text-3xl: 1.875rem;   /* 30px - 首屏大标题 */
--text-5xl: 3rem;       /* 48px - 计时器数字 */
```

**字体引入方式：** Google Fonts 引入霞鹜文楷（中文）和 Nunito（英文），作为 Next.js 的 `next/font` 优化加载。

### 3.3 圆角系统

```css
--radius-sm: 0.75rem;    /* 12px - 小元素（badge、小按钮） */
--radius-md: 1rem;       /* 16px - 输入框、select */
--radius-lg: 1.25rem;    /* 20px - 卡片（默认） */
--radius-xl: 1.5rem;     /* 24px - 大卡片、模态框 */
--radius-2xl: 2rem;      /* 32px - 特殊容器 */
--radius-full: 9999px;   /* 胶囊按钮、圆形 */
```

### 3.4 间距系统

沿用 Tailwind 的 4px 基准网格，但强调关键间距：

```css
--space-page-x: 1.25rem;    /* 页面水平内边距（移动端） */
--space-page-y: 1.5rem;     /* 页面垂直内边距 */
--space-card: 1.25rem;      /* 卡片内边距 */
--space-section: 2rem;       /* 区块间距 */
--space-element: 0.75rem;   /* 元素间距 */
```

### 3.5 阴影系统

```css
/* 柔和、暖调阴影（偏棕而非偏灰） */
--shadow-sm: 0 1px 3px oklch(0.5 0.02 60 / 0.06);
--shadow-md: 0 4px 12px oklch(0.5 0.02 60 / 0.08);
--shadow-lg: 0 8px 24px oklch(0.5 0.02 60 / 0.10);
--shadow-card: 0 2px 8px oklch(0.5 0.02 60 / 0.06),
               0 0 0 1px oklch(0.90 0.02 80 / 0.5);
--shadow-card-hover: 0 6px 20px oklch(0.5 0.02 60 / 0.10),
                     0 0 0 1px oklch(0.58 0.12 155 / 0.2);
```

│  阴影: shadow-card              │  padding: 1.25rem

### 3.7 按钮规范

| 类型 | 样式 | 圆角 | 高度 | 场景 |
|------|------|------|------|------|
| Primary | 鼠尾草绿填充 + 白字 | `full` (胶囊) | 2.75rem (44px) | 主操作（开始记录、提交） |
| Secondary | 暖沙色填充 + 深字 | `full` | 2.75rem | 次要操作 |
| Outline | 透明 + 边框 | `full` | 2.75rem | 辅助操作 |
| Ghost | 透明 + 文字色 | `full` | 2.5rem (40px) | 行内操作（编辑、删除） |
| Destructive | 红色填充 + 白字 | `full` | 2.75rem | 危险操作 |
| Icon | 圆形/方形容器 | `lg` 或 `full` | 2.5rem × 2.5rem | 图标按钮 |

**微交互：**
- 按下：`scale(0.97)` + 轻微亮度变化
- 悬停：`translateY(-1px)` + 阴影增强
- Primary 按钮：计时中添加脉冲动画

### 3.8 导航系统

**桌面端（≥768px）：** 保持顶部导航栏，但增加：
- 当前页面的活跃指示器（底部绿色线条或背景高亮）
- Logo 区域增加小图标（便便 emoji 或自定义图标）
- 导航项间距优化

**移动端（<768px）：** 底部 Tab Bar

```
┌─────────────────────────────┐
│           内容区             │
│                             │
├─────────────────────────────┤
│  🏠    📋    📅    📊    🤖  │  ← 底部 Tab Bar
│  首页  记录  日历  统计  AI  │     高度: 3.5rem + safe-area
└─────────────────────────────┘
```

- 5 个 Tab 对应 5 个路由
- 活跃 Tab 用主色（鼠尾草绿）高亮 + 图标填充变化
- 固定在底部，`backdrop-blur` 毛玻璃效果
- 适配 iPhone 底部安全区 (`pb-safe`)

### 3.9 动画规范

```css
/* 缓动曲线 */
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);       /* 弹性出场 */
--ease-in-out: cubic-bezier(0.65, 0, 0.35, 1);   /* 平滑过渡 */

/* 时长 */
--duration-fast: 150ms;      /* 按钮反馈 */
--duration-normal: 300ms;    /* 卡片展开、路由切换 */
--duration-slow: 500ms;      /* 页面入场 */

/* 关键动画 */
- 页面入场：fadeIn + slideUp，各子元素 stagger 50ms
- 列表项：从下方滑入 + 淡出，stagger 80ms
- 卡片悬停：shadow 增强 + translateY(-2px)
- 计时器开始：按钮脉冲 ring 动画
- 模态框：backdrop fade + 内容 scale(0.95→1) + fade
```

### 3.10 背景纹理

在 `body` 或主容器上添加微妙噪点纹理，增加手工感和温度：

```css
body::after {
  content: '';
  position: fixed;
  inset: 0;
  background-image: url("data:image/svg+xml,..."); /* SVG 噪点 */
  opacity: var(--noise-opacity);
  pointer-events: none;
  z-index: 9999;
}
```

## 四、修改建议（按优先级排序）

### Phase 1：基础层（设计令牌 + 导航 + 字体）

| # | 修改项 | 涉及文件 | 说明 |
|---|--------|---------|------|
| 1 | **重写 `globals.css` 色彩系统** | `globals.css` | 替换全部 CSS 变量为暖色调方案，新增语义色和图表色板 |
| 2 | **引入自定义字体** | `layout.tsx`, `globals.css` | `next/font` 加载霞鹜文楷 + Nunito，替换 Geist |
| 3 | **重构移动端导航** | `layout.tsx`, 新建 `BottomNav.tsx` | 桌面端保留优化后的顶部导航，移动端新增底部 Tab Bar |
| 4 | **导航活跃状态** | `layout.tsx` 或 `NavLink.tsx` | 使用 `usePathname()` 实现当前路由高亮 |

### Phase 2：组件层（卡片 + 按钮 + 表单）

| # | 修改项 | 涉及文件 | 说明 |
|---|--------|---------|------|
| 5 | **升级 Card 组件** | `card.tsx` | 应用新圆角、阴影、悬停动画 |
| 6 | **升级 Button 组件** | `button.tsx` | 胶囊形、新颜色、微交互动画 |
| 7 | **RecordCard 重设计** | `RecordCard.tsx` | 更亲切的布局、图标装饰、更好的信息层次 |
| 8 | **RecordForm 优化** | `RecordForm.tsx` | 分步式或分组式表单，更好的移动端体验 |
| 9 | **替换 `confirm()`** | `RecordCard.tsx`, `detail/page.tsx` | 使用 shadcn/ui Dialog 组件做确认弹窗 |

### Phase 3：页面层（首页 + 统计 + 日历 + AI）

| # | 修改项 | 涉及文件 | 说明 |
|---|--------|---------|------|
| 10 | **首页重设计** | `page.tsx`, `Timer.tsx` | 更突出的计时器、今日数据卡片、空状态插画 |
| 11 | **计时器动画** | `Timer.tsx` | 脉冲环动画、数字翻滚效果、开始/停止过渡 |
| 12 | **统计图表美化** | `StatsCharts.tsx` | 使用设计令牌色板、自定义 tooltip、入场动画 |
| 13 | **日历热力图优化** | `CalendarHeatmap.tsx` | 平滑色阶、今日高亮、更好的空状态 |
| 14 | **AI 分析页面** | `analysis/page.tsx` | 自定义日期选择器、分析卡片重设计 |
| 15 | **全局空状态** | 各页面 | 统一的空状态组件，带插画和引导文案 |

### Phase 4：体验层（动画 + 加载 + 细节）

| # | 修改项 | 涉及文件 | 说明 |
|---|--------|---------|------|
| 16 | **页面切换动画** | `layout.tsx` 或 route wrapper | 使用 framer-motion 或 CSS 实现路由过渡 |
| 17 | **骨架屏** | 新建 `Skeleton*.tsx` | 加载态占位符 |
| 18 | **噪点纹理** | `globals.css` | 全局背景噪点增加温度感 |
| 19 | **深色模式适配** | `globals.css` | 确保暖色调在深色模式下也舒适 |

---

**总结：** 核心改动是将"冰冷的灰度系统模板"转变为"温暖的生活手帐风格"。通过暖色系设计令牌、自定义字体、大圆角胶囊按钮、底部移动端导航、以及微妙的动画和纹理，让这个健康记录工具变得亲切有趣。
